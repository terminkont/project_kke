
# Поставка специализированных клапанов для систем автоматического пожаротушения ГТУ

## Заказчик
ТОО «Азиатский Газопровод»

## Объект
Газотурбинные установки (ГТУ)

## Описание проекта
Проект предусматривает поставку
специализированных клапанов для систем
автоматического пожаротушения газотурбинных
установок (ГТУ) для ТОО «Азиатский Газопровод».

## Цель проекта
Обеспечение систем автоматического
пожаротушения газотурбинных установок
необходимыми клапанами в соответствии
с техническими требованиями заказчика.
