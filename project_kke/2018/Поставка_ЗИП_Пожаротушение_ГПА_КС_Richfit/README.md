
# Поставка ЗИП и блоков системы автоматического пожаротушения для ГПА и КС

## Компания
Richfit International

## Объект
Газоперекачивающие агрегаты (ГПА)
и компрессорные станции (КС)

## Описание проекта
Проект предусматривает поставку запасных
частей, инструментов и принадлежностей (ЗИП),
а также блоков системы автоматического
пожаротушения для газоперекачивающих
агрегатов и компрессорных станций в рамках
контракта компании Richfit International.

## Цель проекта
Обеспечение объектов необходимыми запасными
частями и компонентами систем автоматического
пожаротушения для поддержания работоспособности
оборудования и пожарной безопасности.
