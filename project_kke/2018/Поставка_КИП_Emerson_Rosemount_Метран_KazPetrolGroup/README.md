
# Подбор и поставка КИП Emerson, Rosemount и Метран для месторождений KazPetrolGroup

## Заказчик
KazPetrolGroup

## Объект
Месторождения KazPetrolGroup, Казахстан

## Описание проекта
Проект предусматривает подбор и поставку
контрольно-измерительных приборов (КИП)
Emerson, Rosemount и Метран для
производственных объектов и месторождений
компании KazPetrolGroup.

## Цель проекта
Обеспечение производственных объектов
заказчика контрольно-измерительным
оборудованием в соответствии с техническими
требованиями и условиями эксплуатации.
