
# Разработка и реализация САУ и промышленной сети для АГРС АО «КазТрансГаз Аймак»

## Заказчик
АО «КазТрансГаз Аймак»

## Местоположение
г. Кызылорда и Кызылординская область,
Казахстан

## Объект
Автоматические газораспределительные
станции (АГРС)

## Описание проекта
Проект предусматривает разработку и
реализацию системы автоматического
управления (САУ) и промышленной сети
для автоматических газораспределительных
станций АО «КазТрансГаз Аймак»,
расположенных в городе Кызылорда
и Кызылординской области.

## Цель проекта
Создание системы автоматизированного
управления и промышленной сетевой
инфраструктуры для обеспечения контроля
технологических процессов и обмена
данными на АГРС.
