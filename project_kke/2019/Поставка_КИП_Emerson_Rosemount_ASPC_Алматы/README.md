
# Поставка КИП Emerson и Rosemount для завода ASPC в Алматы

## Объект
Завод по прокату и производству
металлических труб «ASPC»

## Местоположение
Специальная экономическая зона,
г. Алматы, Казахстан

## Описание проекта
Проект предусматривает поставку
контрольно-измерительных приборов (КИП)
производства Emerson и Rosemount
для строительства завода «ASPC»,
специализирующегося на прокате
и выпуске металлических труб,
расположенного в специальной
экономической зоне города Алматы.

## Цель проекта
Обеспечение строящегося промышленного
предприятия современным контрольно-
измерительным оборудованием в соответствии
с техническими требованиями проекта.
