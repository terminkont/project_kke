
# Разработка и внедрение системы удалённого мониторинга 14 газоперекачивающих агрегатов

## Объект
14 газоперекачивающих агрегатов (ГПА)
с турбинами производства General Electric
и Rolls-Royce.

## Описание проекта
Проект предусматривает разработку и
внедрение системы удалённого мониторинга
14 газоперекачивающих агрегатов,
оснащённых турбинами General Electric
и Rolls-Royce.

## Цель проекта
Организация централизованного
дистанционного наблюдения за работой
газоперекачивающих агрегатов и их
технологическими параметрами.
