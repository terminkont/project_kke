
# Аварийное восстановление системы управления нефтеперекачивающим насосом на НПС-9

## Заказчик
Компания «Казахстанско-Китайский Трубопровод»

## Объект
Нефтеперекачивающая станция НПС-9,
нефтепровод «Атасу–Алашанькоу»

## Местоположение
Казахстан

## Описание проекта
Проект предусматривает проведение аварийных
работ по восстановлению работоспособности
системы управления нефтеперекачивающим
насосом на нефтеперекачивающей станции
НПС-9 нефтепровода «Атасу–Алашанькоу»
для компании «Казахстанско-Китайский
Трубопровод».

## Цель проекта
Восстановление работоспособности системы
управления нефтеперекачивающим насосом
и обеспечение надежного функционирования
оборудования станции.
