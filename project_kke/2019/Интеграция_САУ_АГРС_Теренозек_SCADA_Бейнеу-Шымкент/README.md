
# Разработка сетевого решения по интеграции САУ АГРС «Теренозек» в систему SCADA

## Объект
АГРС «Теренозек»,
газопровод «Бейнеу–Шымкент»

## Местоположение
Казахстан

## Описание проекта
Проект предусматривает разработку сетевого
решения для интеграции системы автоматического
управления (САУ) автоматической
газораспределительной станции (АГРС)
«Теренозек» в существующую систему
диспетчерского контроля и сбора данных
(SCADA) газопровода «Бейнеу–Шымкент».

## Цель проекта
Обеспечение передачи технологических данных
между САУ АГРС «Теренозек» и SCADA-системой
газопровода для централизованного мониторинга
технологических процессов.
