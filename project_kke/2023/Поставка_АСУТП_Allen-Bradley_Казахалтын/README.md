
# Поставка оборудования АСУТП Allen-Bradley для Казахалтын Technology

## Заказчик
Казахалтын Technology

## Производитель оборудования
Allen-Bradley (Rockwell Automation)

## Описание проекта
Проект предусматривает поставку
оборудования Allen-Bradley для
автоматизированных систем управления
технологическими процессами (АСУТП)
компании «Казахалтын Technology».

## Цель проекта
Обеспечение производственных объектов
заказчика оборудованием промышленной
автоматизации для поддержания надежной
работы и развития систем управления
технологическими процессами.
