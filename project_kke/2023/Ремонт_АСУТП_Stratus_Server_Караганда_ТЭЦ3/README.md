
# Ремонт АСУ ТП котлоагрегата №8 и турбоагрегата №6 Карагандинской ТЭЦ-3

## Объект
Карагандинская ТЭЦ-3

## Местоположение
г. Караганда, Казахстан

## Оборудование
Stratus Server 4500-1S

## Описание проекта
Проект предусматривает ремонт
автоматизированной системы управления
технологическими процессами (АСУ ТП)
котлоагрегата станции №8 и турбоагрегата
станции №6 Карагандинской ТЭЦ-3 с заменой
полублока сервера Stratus Server 4500-1S.

## Цель проекта
Восстановление работоспособности
и обеспечение надежной эксплуатации
серверного оборудования АСУ ТП
энергетического объекта.
