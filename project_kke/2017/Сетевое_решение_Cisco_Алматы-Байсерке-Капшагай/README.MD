
# Разработка сетевого решения и поставка оборудования Cisco для газопровода «Алматы–Байсерке–Капшагай»

## Объект
Газопровод «Алматы–Байсерке–Капшагай»,
Казахстан

## Описание проекта
Проект предусматривает разработку сетевого
решения и поставку промышленного сетевого
оборудования Cisco для организации передачи
технологических данных газопровода
«Алматы–Байсерке–Капшагай».

## Цель проекта
Создание надежной сетевой инфраструктуры
для передачи технологической информации
между объектами газопровода с применением
промышленных коммутаторов Cisco.
