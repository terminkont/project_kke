
# Подбор и поставка высокотехнологичных КИП по давлению Siemens и WIKA для Maersk Oil

## Заказчик
Maersk Oil

## Объект
Месторождение Дунга, Казахстан

## Описание проекта
Проект предусматривает оперативный подбор
и поставку высокотехнологичных
контрольно-измерительных приборов (КИП)
для измерения давления производства
Siemens и WIKA на месторождение Дунга
для компании Maersk Oil.

## Цель проекта
Обеспечение заказчика необходимыми
приборами измерения давления в сжатые
сроки с учетом технических требований
и условий эксплуатации.
