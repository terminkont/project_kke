
# Модификация и повторная интеграция логики Master PLC воздушных компрессоров KEP1A в систему ICSS

## Заказчик
MERLION-SICIM

## Конечный пользователь
КПО (Карачаганак Петролиум Оперейтинг)

## Объект
Воздушные компрессоры KEP1A

## Описание проекта
Проект предусматривает оказание услуг
по модификации и повторной интеграции
логики главного программируемого
логического контроллера (Master PLC)
воздушных компрессоров KEP1A
в интегрированную систему управления
и безопасности (ICSS).

## Цель проекта
Обеспечение корректного взаимодействия
логики Master PLC воздушных компрессоров
KEP1A с существующей системой ICSS.
