
# Поставка оборудования Honeywell для КПО

## Заказчик
КПО (Карачаганак Петролиум Оперейтинг)

## Описание проекта
Проект предусматривает поставку промышленного
оборудования Honeywell для нужд КПО
(Карачаганак Петролиум Оперейтинг).

## Цель проекта
Обеспечение предприятия необходимым
оборудованием Honeywell в соответствии
с техническими требованиями
и потребностями заказчика.
