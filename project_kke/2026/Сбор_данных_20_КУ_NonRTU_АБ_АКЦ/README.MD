
# Проект сбора и передачи данных с 20 крановых узлов NonRTU ниток А и Б в АКЦ

## Год реализации
2026

## Описание проекта
Проект предусматривает организацию сбора
и передачи данных с 20 крановых узлов
NonRTU, расположенных на нитках А и Б,
в АКЦ.

## Основные задачи
- Организация сбора данных с 20 крановых узлов.
- Передача данных с ниток А и Б в АКЦ.
- Обеспечение централизованного получения информации.
