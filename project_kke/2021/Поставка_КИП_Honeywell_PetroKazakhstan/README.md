
# Поставка КИП производства Honeywell для PetroKazakhstan

## Заказчик
PetroKazakhstan

## Описание проекта
Проект предусматривает поставку
контрольно-измерительных приборов (КИП)
производства Honeywell для производственных
нужд компании PetroKazakhstan.

## Цель проекта
Обеспечение производственных объектов
заказчика контрольно-измерительным
оборудованием Honeywell в соответствии
с техническими требованиями и условиями
эксплуатации.
