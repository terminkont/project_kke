
# Разработка и внедрение системы сбора технологических данных с беспроводными КИП Honeywell

## Объект
Газопровод «Казахстан–Китай»

## Местоположение
Казахстан

## Описание проекта
Проект предусматривает разработку и
внедрение системы сбора технологических
данных с применением беспроводных
контрольно-измерительных приборов (КИП)
Honeywell и интеграцию получаемой информации
в существующую SCADA-систему газопровода
«Казахстан–Китай».

## Цель проекта
Организация беспроводного сбора
и централизованного мониторинга
технологических параметров газопровода
с передачей данных в действующую
SCADA-систему.
