
# Разработка САУ насосами подачи воды для жилого комплекса BI-Group

## Заказчик
BI-Group

## Субподряд
Компания Gateway

## Местоположение
г. Астана, Казахстан

## Объект
Система водоснабжения жилого комплекса BI-Group

## Описание проекта
Проект предусматривает разработку системы
автоматического управления (САУ) насосами
подачи воды для жилого комплекса BI-Group
в городе Астана. Работы выполняются
в рамках субподряда от компании Gateway.

## Цель проекта
Создание системы автоматического управления
насосным оборудованием для обеспечения
стабильной подачи воды и надежной работы
системы водоснабжения жилого комплекса.
