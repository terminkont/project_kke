
# Интеграция данных систем управления газокомпрессорных станций и разработка HMI для SCADA

## Объект
Газокомпрессорные станции газопровода
«Бейнеу–Шымкент»

## Местоположение
Казахстан

## Описание проекта
Проект предусматривает интеграцию
технологических данных из систем управления
газокомпрессорных станций и разработку
человеко-машинного интерфейса (HMI)
для существующей SCADA-системы
газопровода «Бейнеу–Шымкент».

## Цель проекта
Обеспечение централизованного мониторинга
технологических параметров газокомпрессорных
станций и удобного отображения информации
для операторов SCADA-системы.
