
# Модернизация САУ АГРС «Нововоскресеновка»

## Заказчик
АО «Интергаз Центральная Азия»

## Объект
Автоматическая газораспределительная
станция (АГРС) «Нововоскресеновка»

## Описание проекта
Проект предусматривает модернизацию
системы автоматического управления (САУ)
автоматической газораспределительной
станции «Нововоскресеновка» для
АО «Интергаз Центральная Азия».

## Цель проекта
Повышение надежности и эффективности
автоматического управления технологическими
процессами газораспределительной станции.
