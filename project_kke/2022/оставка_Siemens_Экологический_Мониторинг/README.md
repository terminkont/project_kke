
# Поставка оборудования Siemens для проекта экологического мониторинга промышленных выбросов

## Производитель оборудования
Siemens

## Описание проекта
Проект предусматривает поставку
промышленного оборудования Siemens
для реализации системы экологического
мониторинга выбросов на производственных
объектах.

## Цель проекта
Обеспечение проекта экологического
мониторинга техническими средствами
для контроля параметров промышленных
выбросов и сбора данных о состоянии
окружающей среды.
