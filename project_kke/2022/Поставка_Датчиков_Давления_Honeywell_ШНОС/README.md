
# Поставка датчиков давления с выносными диафрагмами Honeywell для ШНОС

## Заказчик
ШНОС (Шымкентский нефтеперерабатывающий завод)

## Местоположение
г. Шымкент, Казахстан

## Описание проекта
Проект предусматривает поставку датчиков
давления с выносными разделительными
диафрагмами производства Honeywell
для технологических нужд Шымкентского
нефтеперерабатывающего завода (ШНОС).

## Цель проекта
Обеспечение предприятия контрольно-
измерительным оборудованием для измерения
давления в технологических процессах
нефтепереработки.
