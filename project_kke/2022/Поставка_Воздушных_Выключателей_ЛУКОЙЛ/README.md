
# Поставка воздушных автоматических выключателей для «ЛУКОЙЛ Лубрикантс Центральная Азия»

## Заказчик
«ЛУКОЙЛ Лубрикантс Центральная Азия»

## Описание проекта
Проект предусматривает поставку воздушных
автоматических выключателей для обеспечения
потребностей предприятия «ЛУКОЙЛ Лубрикантс
Центральная Азия» в электротехническом
оборудовании.

## Цель проекта
Обеспечение предприятия надежными
коммутационными аппаратами для защиты
электрических сетей и оборудования
от перегрузок и коротких замыканий.
