
# Поставка оборудования Honeywell, Endress+Hauser, WIKA и AUMA для Карачаганак ЮНИТ-3

## Объект
Воздушный компрессор Карачаганак ЮНИТ-3

## Местоположение
Карачаганакское нефтегазоконденсатное
месторождение, Казахстан

## Производители оборудования
- Honeywell
- Endress+Hauser
- WIKA
- AUMA

## Описание проекта
Проект предусматривает поставку
промышленного оборудования производителей
Honeywell, Endress+Hauser, WIKA и AUMA
для воздушного компрессора ЮНИТ-3
на Карачаганакском нефтегазоконденсатном
месторождении.

## Цель проекта
Обеспечение компрессорного оборудования
необходимыми компонентами контрольно-
измерительных приборов, промышленной
автоматизации и управления в соответствии
с техническими требованиями проекта.
