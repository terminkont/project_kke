
# Инжиниринг и внедрение систем ПАЗ и САУ для объектов газоснабжения г. Алматы

## Объект
АГРС ТЭЦ-3 и узел учета газа TIP-04

## Местоположение
г. Алматы, Казахстан

## Проект
Газификация ТЭЦ

## Описание проекта
Проект предусматривает выполнение
инжиниринговых работ и внедрение систем
противоаварийной защиты (ПАЗ)
и автоматического управления (САУ)
для объектов газоснабжения города Алматы —
АГРС ТЭЦ-3 и узла учета газа TIP-04
в рамках проекта газификации ТЭЦ.

## Цель проекта
Обеспечение надежного автоматизированного
управления и противоаварийной защиты
технологических процессов на объектах
газоснабжения энергетической
инфраструктуры города Алматы.
