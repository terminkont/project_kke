
# Поставка преобразователей давления Honeywell для Air Liquide Munay Tech Gases LLP

## Заказчик
Air Liquide Munay Tech Gases LLP

## Производитель оборудования
Honeywell

## Объект
Производственные установки компании
Air Liquide Munay Tech Gases LLP

## Описание проекта
Проект предусматривает поставку
преобразователей давления производства
Honeywell для использования на промышленных
установках компании Air Liquide Munay
Tech Gases LLP.

## Цель проекта
Обеспечение производственных установок
надежными контрольно-измерительными
приборами для контроля давления
и поддержания стабильной работы
технологического оборудования.
