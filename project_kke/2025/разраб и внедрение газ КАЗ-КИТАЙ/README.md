
# Разработка и внедрение системы сбора технологических данных на газопроводе «Казахстан–Китай»

## Год реализации
2025

## Местоположение
Туркестанская область, Казахстан

## Описание проекта
Проект направлен на разработку и внедрение
системы сбора технологических данных
с применением контрольно-измерительных
приборов (КИП) Honeywell и интеграцию
полученной информации в существующую
SCADA-систему газопровода «Казахстан–Китай».

## Цель проекта
Организация централизованного сбора,
передачи и отображения технологических
данных в существующей SCADA-системе.
