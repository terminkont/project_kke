
# Поставка запасных частей для ремонтно-эксплуатационных нужд (РЭН) КС газопровода «Бейнеу–Шымкент»

## Объект
Газопровод «Бейнеу–Шымкент», Казахстан

## Описание проекта
Проект предусматривает поставку оборудования
и запасных частей для ремонтно-эксплуатационных
нужд (РЭН) компрессорных станций (КС)
газопровода «Бейнеу–Шымкент».

## Цель проекта
Обеспечение компрессорных станций
необходимыми запасными частями и
оборудованием для проведения технического
обслуживания и ремонтных работ.
